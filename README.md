# Kunal Kishore — Product Management Portfolio

MBA candidate at IIM Kashipur building hands-on projects in e-commerce seller experience, product analytics, and logistics.

This portfolio brings together three capabilities: support-product prototyping, data-driven product decisions, and operational workflow design.

---

## 1. Seller Support Copilot

A retrieval-based support prototype that answers routine shipping questions using a hypothetical FAQ knowledge base and flags sensitive or unsupported queries for human review.

### Project highlights
- Created a 46-entry hypothetical knowledge base covering tracking, pickups, returns, billing, and account support.
- Built a Python and Streamlit chat interface with FAQ source references and rule-based escalation.
- Designed a 49-question evaluation dataset covering answer correctness, groundedness, and escalation behavior.
- Authored a product requirements document and evaluation framework.

Tools: Python, Streamlit, Pandas

## 2. Seller Onboarding Analytics

A product analytics case examining where fictional sellers drop off between account creation and their first shipment pickup.

### Project highlights
- Analyzed 7,444 synthetic events across 3,000 sellers using SQL and SQLite.
- Built an interactive Streamlit dashboard with onboarding funnel, device, and acquisition-channel analysis.
- Identified business-detail completion as the largest absolute drop-off in the synthetic funnel.
- Designed an A/B experiment with primary metrics, guardrails, and an approximate sample requirement of 1,500 sellers per variant.

Tools: SQL, SQLite, Python, Pandas, Streamlit

[Live Demo](https://seller-app-analytics-7o8pg9cq35ifmy8debbcka.streamlit.app/)

[View Code & Documentation](https://github.com/kunalkishoreconnect/seller-onboarding-analytics)

## 3. Shipment Exception Manager

An operational workflow prototype that helps sellers identify shipment exceptions, prioritize follow-ups, assign ownership, and track resolution.

### Project highlights
- Built a dashboard using 120 synthetic shipments with exception classification and priority-based filtering.
- Added simulated case ownership, resolution tracking, customer-message drafts, and session action logs.
- Authored a PRD, user stories, acceptance criteria, assumption-based RICE prioritization, and measurement plan.
- Validated exception-classification logic with seven passing automated rule tests.

Tools: Python, Streamlit, Pandas, Unit Testing
